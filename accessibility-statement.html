Commitment

This project targets WCAG 2.2 AA-level practical outcomes for keyboard users, screen-reader users, low-vision users, and mobile users.

Known limitations

  • Automated accessibility tests cannot verify all real-world assistive technology behavior.
  • Live station data fetching may be blocked by CORS in GitHub Pages browser contexts.

Feedback channel

Open a GitHub issue with reproducible steps, browser details, and assistive technology details where possible.
